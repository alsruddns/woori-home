## Lowest-cost paths worth pursuing

- **Crypto screen display:** CoinGecko Basic is the only reviewed, clearly priced route that expressly includes paid commercial customer-facing display and historical data: $35 monthly, or $29/month on annual billing, with required prominent attribution. Its standard plan does not clear reusable public API delivery. If a separate server-rendered/display-only path cannot be kept within those rights, obtain written custom terms before enabling prices.
- **US equities:** Twelve Data Venture currently starts at $499/month. Its publicly listed US Equities external-distribution add-on starts at $2,400/year; global EOD external distribution is quote-only. The default US feed is sourced from venues representing roughly 5% of reported total US trading volume. Obtain a precise quote for the desired EOD feed and site/API delivery before selecting it.
- **Korean equities and indexes:** the free KRX OPEN API is not eligible for the ad-supported public service. Request a KRX/KOSCOM commercial quote for exact EOD data. No fee should be estimated until a written quote is received.
- **Exchange APIs (Upbit, Bithumb, Binance):** public endpoint access is technically free, but no reviewed official source confirms the complete advertised display/storage/API use. Request permission; do not use API availability as a license.
